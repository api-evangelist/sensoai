# Senso.ai

> Senso.ai is a verified-context layer for the agentic web. Teams ingest raw sources into a knowledge base, run semantic search that returns an AI-generated answer plus source chunks, and generate verified, on-brand content. Senso also tracks how AI assistants (OpenAI, Gemini, Amazon Nova) answer about a brand and remediates incorrect answers (generative engine optimization). The Senso Org API is a key-authenticated REST API with an official CLI and an MCP server.

Note: This llms.txt was generated by the API Evangelist enrichment pipeline from the public Senso developer surface (Senso does not publish an llms.txt; docs.senso.ai/llms.txt returns the docs SPA, not a real file).

## API

- [Senso Org API — base URL](https://apiv2.senso.ai/api/v1): REST API. Auth: X-API-Key header (keys prefixed tgr_). Core operations: POST /content/raw (ingest), POST /search (semantic search + AI answer), POST /generate (generate verified content).
- [API reference](https://docs.senso.ai/api-reference)
- [Quickstart / hello-world](https://docs.senso.ai/docs/hello-world)
- [Authentication](https://docs.senso.ai/docs/authentication)

## Developer tools

- [Official CLI (@senso-ai/cli)](https://www.npmjs.com/package/@senso-ai/cli): `npm install -g @senso-ai/cli`. Every Org API endpoint as a command; agent-friendly with `--output json --quiet`.
- [MCP server (api-mcp-server)](https://github.com/AI-Template-SDK/api-mcp-server): official stdio Model Context Protocol server for Claude Desktop — add_raw_content, search_content, generate_content, and prompt/template tools.
- [GitHub organization (AI-Template-SDK)](https://github.com/AI-Template-SDK): CLI, MCP server, api-quickstart examples, senso-workflows.
